Whatsapp_Osint_analyzer

УСТАНОВКА НА WINDOWS
1. Распакуйте весь архив в отдельную папку, не поверх старой сборки.
2. Установите Python 3.11 x64 с Python Launcher (команда py).
3. Запустите INSTALL.bat. Интернет нужен для установки библиотек.
4. Для аудио один раз запустите DOWNLOAD_MODEL.bat. Он скачивает многоязычную
   модель small в models/small. Выделите несколько гигабайт свободного места
   под библиотеки, модель и временные файлы сборки.
5. Запускайте START.bat. Обработка материалов работает локально.

Не запускайте старый EXE из прежнего архива: он не содержит этих изменений.
Прямой запуск main.py выполняйте через .venv\Scripts\python.exe main.py,
чтобы использовать установленные зависимости.

ДОКУМЕНТЫ
Откройте «Документы» → «Загрузить документы», выберите TXT/DOCX/PDF.
Автоанализ начинается сразу, без поискового запроса. Ожидайте завершения:
статус показывает этап извлечения и число обработанных блоков.
В режиме «Автоанализ» видны категория, уровень угрозы, найденные слова и
фрагмент. Поисковая строка фильтрует автоматические результаты, Enter применяет
фильтр. Очистите строку и нажмите Enter, чтобы вернуть все срабатывания.
Режим «Поиск текста» ищет введённую фразу во всём извлечённом тексте.
Двойной щелчок по строке открывает объяснение, фрагмент и исходный блок.
CSV сохраняет все результаты текущего режима и фильтра, включая объяснения.
Таблица отображает до 2000 результатов; CSV содержит весь выбранный набор.
TXT: блок — строка; DOCX: абзац основного текста/таблицы; PDF: страница.
Для автоматического анализа блок дополнительно разделяется на предложения
и строки. Между разными документами контекст не переносится. Далёкий текст
на странице не используется как подтверждение намерения в конкретной фразе.
Сканированные PDF без текста требуют OCR, который пока не добавлен.
Колонтитулы DOCX не извлекаются. DOC/RTF не поддержаны.
Новая загрузка заменяет набор документов, но не переписки WhatsApp.
Исходные файлы не изменяются. Результаты находятся в памяти до закрытия.

ОБНОВЛЁННЫЕ ПРАВИЛА
Расширен словарь сленга и выражений по существующим семи категориям.
Одинаковые правила применяются к документам и перепискам WhatsApp.
Добавлены отдельные формы слов, выбранные опечатки и варианты транслита,
а также написание некоторых терминов с разделителями и смешением алфавитов.
Произвольные шифры не расшифровываются; неизвестный сленг может быть пропущен.
Общие слова («данные», «доступ», «план» и др.) требуют дополнительного признака.
«Соль», «трава» и другие неоднозначные обозначения не повышают уровень сами
по себе; известные бытовые обороты исключаются. Отрицания, пересказ и учебные
формулировки учитываются эвристически, в ограниченном контексте.
Прямые выражения и подтверждённые условия правил определяют уровень без баллов.
Каждое срабатывание требует проверки человеком; оно не устанавливает факт
преступления или намерение автора. Это правила, не языковая модель.
Для проверки вручную приложен файл AUTO_ANALYSIS_EXAMPLE.txt с вымышленными
фразами: сначала загрузите его в «Документы» и дождитесь автоанализа.

АУДИО
Откройте «Аудио», выберите запись, папку модели и язык (или «Авто»).
Нажмите «Расшифровать». Используется CPU, отдельная видеокарта не требуется.
Поддерживаемые расширения в диалоге: WAV, MP3, M4A, OGG, OPUS, FLAC, AAC, MP4.
Возможность декодирования конкретной записи зависит от её кодека/содержимого.
Появляются фрагменты с началом и концом. Enter в строке поиска фильтрует текст.
«Сохранить» выгружает полную полученную расшифровку в TXT или SRT независимо
от фильтра. Двойной щелчок показывает текст и временные метки фрагмента.
«Остановить» действует между фрагментами; загрузка модели и текущий расчёт
могут завершаться не сразу. Частичный TXT отмечается как неполный.
SRT содержит только стандартные субтитры; полноту сверяйте со статусом окна.
Автоматический текст может ошибаться — сверяйте имена, числа и фразы с записью.
Распознавание может занимать больше времени, чем длится сама запись.
Раздел не определяет личности говорящих и не разделяет их автоматически.
Перед выбором новой записи сохраните результат. Закрытие удаляет его из памяти.

МОДЕЛЬ РЕЧИ И АВТОНОМНОСТЬ
Модель не включена в архив и не загружается самим приложением.
DOWNLOAD_MODEL.bat отдельно скачивает только модель из репозитория
Systran/faster-whisper-small. Материалы пользователя скрипт не читает.
Для изолированного компьютера перенесите полную папку models/small с другого
компьютера и выберите её в интерфейсе. Нужны model.bin, config.json,
tokenizer.json, а также остальные файлы модели. preprocessor_config.json
необязателен: при его отсутствии используются параметры faster-whisper по умолчанию.
Модели оригинального whisper формата .pt не подходят.
При установленной модели интернет для расшифровки не нужен.

КАРТА СОБЫТИЙ
«Добавить»: название, дата, широта, долгота, источник и описание.
Дата необязательна: 2026-10-10 14:30. Часовой пояс самостоятельно приводите
к одной системе; приложение не определяет его по источнику.
Координаты десятичные; широта от -85.05112878 до 85.05112878, долгота -180..180.
События вводятся вручную: программа не угадывает адреса по тексту.
Двойной щелчок по карте открывает добавление с координатами указанной точки.
Перетаскивание — перемещение; колесо мыши / + / − — масштаб.
Выбор строки центрирует карту; двойной щелчок по строке — редактирование.
Поиск фильтрует список и точки по названию, дате, описанию и источнику.
Список отсортирован по дате. Источник — поле для ссылки на файл/страницу/время;
сам файл не копируется в набор событий.
«Сохранить JSON» сохраняет весь набор; «Открыть JSON» заменяет текущий набор.
При закрытии есть запрос на сохранение изменённых событий.

ОФЛАЙН-ПОДЛОЖКА
По умолчанию видна координатная сетка с точками, без дорог и границ.
Для географической подложки выберите готовый растровый файл .mbtiles кнопкой
«Карта MBTiles». Карты не включены в архив и из интернета не подгружаются.
Поддержаны PNG/JPEG/WebP-тайлы в Web Mercator, стандартный порядок строк TMS.
Векторные MBTiles/PBF не поддержаны. Масштаб ограничен уровнями загруженного
файла. За пределами покрытия видна сетка. Атрибуция берётся из metadata.
Используйте подготовленную карту нужного района с правом её использования.

СБОРКА EXE
После INSTALL.bat запустите build_windows.bat на Windows.
Результат: dist\Whatsapp_Osint_analyzer.exe. Включены библиотеки новых функций.
Модель речи и MBTiles остаются внешними файлами. При сборке скачанная модель
автоматически копируется из models/small в dist/models/small. Если копирование
не удалось, скрипт сообщает об этом. Карта MBTiles выбирается в интерфейсе.
Можно скопировать models рядом с EXE, чтобы папка модели подставлялась сама.
Один EXE с библиотеками будет существенно крупнее старой сборки; первый запуск
может быть медленным из-за распаковки. Не прерывайте его преждевременно.

ИЗМЕНЕНИЯ И АРХИТЕКТУРА
main.py: три новых раздела, фоновые задачи, интерфейс карты и экспорт.
analyzer.py: извлечение/поиск документов, локальное распознавание, события,
проекция координат и чтение MBTiles.
patterns.py: существующие правила анализа переписок сохранены.
Тёмно-синий дизайн и прежние функции WhatsApp сохранены.
Нет новых номеров версии и рекламных надписей в интерфейсе.
Все результаты поиска и распознавания служат материалом для проверки человеком.

По просьбе пользователя приложение, тесты и сборка EXE при подготовке этого
архива НЕ запускались. Это исходники и сценарии установки, не проверенный EXE.

ИСПРАВЛЕНИЕ ПУТИ МОДЕЛИ И ЛОГОТИПА
EXE ищет полную модель рядом с собой в models/small, затем на уровень выше
в папке проекта. При ручном выборе используется выбранная папка.
Буква W в боковой панели заменена существующей иконкой программы icon.ico.
Для обновления замените main.py, analyzer.py и build_windows.bat; затем
пересоберите EXE. Существующие models и .venv не удаляйте.

ПОИСК ПО НОМЕРУ ТЕЛЕФОНА
После обновления запустите INSTALL.bat: добавлена библиотека phonenumbers.
Введите международный номер с +. «Проверить локально» покажет справочные
страну, регион нумерации, оператора из базы и возможные часовые пояса.
Эти данные не устанавливают владельца, активность SIM или местоположение.
Для онлайн-поиска отметьте сервис, введите свой ключ и разрешите передачу
номера. Нажмите «Поиск в интернете». Numverify возвращает сведения о номере,
SerpAPI и GitHub — до 10 ссылок на публичные упоминания каждого источника.
Совпадение поисковой выдачи не подтверждает принадлежность номера человеку.
GitHub запрашивает только публичный код, содержимое файлов не скачивается.
Numverify используется только через HTTPS: если тариф его не допускает,
выводится ошибка; перехода на HTTP нет. Бесплатность и квоты не гарантируются:
они определяются текущими условиями вашего аккаунта, не цифрами из SearchPhone.
Ключи задаются в интерфейсе или переменных окружения NUMVERIFY_KEY,
SERPAPI_KEY, GITHUB_TOKEN, OPENCAGE_KEY. В файлы приложения они не сохраняются.
OpenCage работает отдельно: введите город/адрес в нижней строке, отметьте
OpenCage, укажите ключ и нажмите «Найти место». Это координаты места,
а не геолокация телефона. Автоматической отправки координат на карту нет.
«Сохранить JSON» сохраняет последний показанный результат без API-ключей.
Для авторизации создавайте ключи на официальных сайтах сервисов; в чат
ключи отправлять не нужно. Без них работает только локальная проверка.
Вкладка реализована напрямую через API, сам сторонний SearchPhone не включён.
Hudson Rock и сбор украденных учётных данных не интегрированы.
Приложение и сборка не запускались, реальные API-запросы не проверялись.
https://opencagedata.com/api
https://numverify.com/documentation
https://serpapi.com/search-api
https://docs.github.com/en/rest/search/search


ПОИСК ПУБЛИЧНЫХ УПОМИНАНИЙ НОМЕРА
1. Откройте вкладку «Поиск по номеру», введите номер с + и кодом страны.
2. Для Google включите SerpAPI и вставьте ключ: https://serpapi.com/manage-api-key
3. Дополнительный независимый источник — Brave Web Search API. Получите ключ в https://api-dashboard.search.brave.com/ и вставьте в поле Brave. Доступ и квоты зависят от выбранного тарифа.
4. Можно включить один поисковик или оба. Отметьте согласие на отправку номера и нажмите «Поиск в интернете».
Один запуск отправляет один запрос каждому выбранному поисковику, объединяя варианты номера оператором OR. Учитывайте расход квоты даже при пустой выдаче.
Выдаются заголовки, ссылки и фрагменты проиндексированных страниц. Страницы автоматически не скачиваются. Ссылку можно скопировать из результата в браузер. Совпадения не подтверждают личность владельца. Закрытые профили, базы операторов и утечки не используются.
GitHub ищет только публичный код. Numverify даёт справочные сведения. OpenCage обрабатывает введённый адрес, а не местоположение телефона.
Ключи хранятся в памяти сеанса, не включаются в JSON. JSON сохраняет исходные справочные данные, включая неоднозначные часовые пояса; в экранном отчёте неоднозначность обозначена явно.

Приложение и тесты при подготовке этого обновления не запускались.
